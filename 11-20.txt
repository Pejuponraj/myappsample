18.Time Intelligence Functions

  | **Function**            | **Use Case**                                        |
|-------------------------|-----------------------------------------------------|
| `TOTALYTD()`            | **Year-to-Date** calculations (e.g., sales from the start of the year to the current date) |
| `TOTALQTD()`            | **Quarter-to-Date** calculations (e.g., sales from the start of the quarter to the current date) |
| `TOTALMTD()`            | **Month-to-Date** calculations (e.g., sales from the start of the month to the current date) |
| `SAMEPERIODLASTYEAR()`  | **Same period last year** comparison (e.g., YoY comparison) |
| `PARALLELPERIOD()`      | **Fixed period shift** (e.g., comparing this month to the same month last year or last quarter) |
| `DATEADD()`             | **Shifting dates** by a fixed interval (e.g., previous month, next quarter) |
